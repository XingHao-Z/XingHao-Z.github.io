# 1. 电阻基本概念

电阻描述的是一个器件对电流流动的阻碍程度，单位是欧姆

欧姆定理：$V=IR$

对于一个均匀材料：$R = \rho \frac{L}{A}$

其中：$\rho$：电阻率；$L$：导体长度；$A$：截面积



# 2. 电阻基本参数

## 2.1. 阻值

实际生产的电阻并不是任意阻值都有，而是按照E系列（E-Series）阻值进行设置。

E 系列由国际电工委员会（IEC）标准定义，常见包括：E6, E12, E24, E48, E96, E192。其中的数字代表每一个十倍范围内包含的标准阻值数量。例如E12，表示一个十倍程范围包含12个阻值。

E系列的取值方式可以用等比数列表示：$R_{k,m} = 10^m \cdot 10^{k/N}$

其中：

$N=6,12,24,48,96,192$：对应各个E系列；

$k=0,1,2,…,N−1$：表示一个十倍程内第$k+1$个阻值;

$m$：自然数，确定数量级

比如常见的：R=4.99kΩ，就是E96系列中，当m=3时第60个阻值。

## 2.2. 精度：

常见电阻精度：20%；10%；5%；2%；1%。

对于贴片电阻型号标注：

M：20%；K：10%；J：5%；G：2%；F：1%

## 2.3. 封装

对于贴片电阻，封装一般是以电阻实际的英制尺寸命名。如0603：0.06英寸×0.03英寸

常见封装：1206、0805、0603、0402、0201、01005

## 2.4. 额定功率

贴片电阻的额定功率主要和封装相关。一般封装和额定功率关系为：

| 封装  | 额定功率 / W |
| ----- | ------------ |
| 1206  | 1/4          |
| 0805  | 1/8          |
| 0603  | 1/10         |
| 0402  | 1/16         |
| 0201  | 1/20         |
| 01005 | 1/32         |

但实际和不同厂家不同工艺也有关，另外额定功率只在规定温度条件下成立。实际参考数据手册。

## 2.5. 温度系数

温度系数，也叫温漂，TCR：Temperature Coefficient of Resistance

单位：$ppm/^\circ C$，（part per million）百万分之几。

贴片电阻常见TCR：±5 ~ ±200 ppm/°C
